# Human Quick Start

## What This Is

`ai_usage_wizard/` is a portable AI-assisted development workflow kit.

It helps the AI agent guide you through common software work without requiring you to memorize the process.

## How To Start

In your AI coding tool, type:

```text
read ai_usage_wizard
```

The agent should show a menu like:

```text
1. Start a new project
2. Enhance an existing project
3. Fix a bug
4. Address technical debt
5. Design or review architecture
...
```

Choose the closest option.

## How To Use It

The agent will:

1. select the workflow
2. ask focused questions
3. identify risk level and gates
4. walk through the workflow phase by phase
5. pause for your decisions
6. help validate work
7. help summarize durable context

## Important Principle

The AI guides the process, but the developer owns decisions, architecture, correctness, and final approval.
