# Phase 2: Reproduction

## Purpose

Reproduce or characterize the defect before fixing it.

## Ask / Inspect

1. What exact steps reproduce the issue?
2. Is there a failing test?
3. Can we create a minimal failing test?
4. If not reproducible yet, what evidence narrows the cause?

## Produce

- reproduction steps or characterization
- failing test candidate
- affected input/output
- confidence level

## Stop / Continue

Ask whether to revise reproduction or continue to root cause analysis.
