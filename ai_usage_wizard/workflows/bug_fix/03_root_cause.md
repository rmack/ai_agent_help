# Phase 3: Root Cause

## Purpose

Identify why the defect occurs before fixing it.

## Ask / Inspect

1. What code path likely causes the issue?
2. What assumption is wrong?
3. What contract or validation failed?
4. Why did existing tests not catch it?

## Produce

- likely root cause
- supporting evidence
- affected files/modules
- test gap
- regression risk

## Stop / Continue

Ask whether to revise root cause or continue to fix plan.
