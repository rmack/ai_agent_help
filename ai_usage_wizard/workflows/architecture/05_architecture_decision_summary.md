# Phase 5: Architecture Decision Summary

## Purpose

Capture the durable architecture decision before implementation or handoff.

## Input

Use the accepted outputs from phases 1-4.

## Produce

Use `templates/architecture_decision.md` and include:

- decision
- context
- options considered
- selected approach
- reasons
- tradeoffs
- consequences
- follow-up tasks

## Stop / Continue

After producing the decision summary, ask:

```text
Do you want to:
1. Revise this architecture decision summary
2. Create an implementation plan
3. Create a Markdown memory file
4. Stop here
```
