# Phase 2: Characterization

## Purpose

Understand and protect existing behavior before refactoring.

## Ask / Inspect

1. What current behavior must be preserved?
2. What tests already cover it?
3. Are characterization tests needed?
4. What outputs or workflows should remain identical?

## Produce

- current behavior summary
- existing test coverage
- needed characterization tests
- regression risks

## Stop / Continue

Ask whether to add characterization or continue to refactor boundary.
