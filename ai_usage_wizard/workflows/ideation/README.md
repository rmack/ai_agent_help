# Ideation / Brainstorm Workflow

Use this workflow when exploring ideas, comparing options, discussing strategy, or intentionally allowing tangents.

## Purpose

Support broad thinking while preserving useful ideas as durable memory.

## Agent Rules

- Do not force premature implementation.
- Distinguish ideas, decisions, assumptions, and open questions.
- Capture tangents as possible future thread seeds.
- Offer summaries when the discussion branches.

## Wizard Questions

```text
Selected workflow: Ideation / Brainstorm
Process weight: Lightweight or Standard unless architecture/security decisions are involved.
Mode: Exploration

Answer what you can:
1. What topic are we exploring?
2. Are we trying to decide, generate options, understand a topic, or challenge assumptions?
3. Should I actively capture tangents as future-thread seeds?
4. Should the output be notes, options, recommendation, or a Markdown summary?
```

## Process

1. Clarify topic and desired output.
2. Explore options, levels, and tradeoffs.
3. Identify tangents.
4. Periodically summarize major topics.
5. Capture decisions and open questions.
6. Offer to create a Markdown memory file.

## Tangent Capture Prompt

```text
Summarize the main topics we have discussed so far.

For each topic include:
- topic name
- why it came up
- key points
- decisions made
- open questions
- whether this belongs in the current thread or should become a separate thread
```
