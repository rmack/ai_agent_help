# Presentation Assets

This directory contains presentation material for explaining the AI-assisted development workflow.

## Files

| File | Format | Purpose |
| --- | --- | --- |
| `ai_assisted_development_workflow.pdf` | PDF export | Viewable/shareable version of the presentation. |
| `pptx/ai_assisted_development_workflow.pptx` | PowerPoint source | Editable source deck for updates and future exports. |

## Usage

Use the PDF when you need a stable presentation artifact for review or distribution.

Use the PowerPoint file when making slide changes, then export a new PDF after edits are complete.

## Maintenance Notes

Keep editable source files under `pptx/`.

Keep exported presentation files, such as PDFs, directly in this directory unless more export formats are added later.
